# RetailPulse - AI Powered Retail Analytics & Demand Forecasting

## Project Overview

RetailPulse is an AI-powered Customer Analytics and Demand Forecasting platform developed using Python and Machine Learning.

The project analyzes retail transaction data to discover customer purchasing behavior, product performance, sales trends, country-wise revenue distribution, and future demand predictions.

The goal is to help retailers make data-driven decisions for inventory planning, customer targeting, and revenue optimization.
