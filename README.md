# RetailPulse: AI Powered Retail Analytics & Demand Forecasting

## Overview

RetailPulse is an AI-powered retail analytics platform built using Python, Machine Learning, and Streamlit. It helps businesses analyze sales performance, forecast future demand, segment customers, recommend products, and predict customer churn.

## Features

* Sales Analysis and Visualization
* Demand Forecasting
* Customer Segmentation using K-Means
* Product Recommendation System
* Customer Churn Prediction
* Interactive Streamlit Dashboard

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn
* Streamlit

## Dataset

Online Retail Dataset

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. Demand Forecasting
4. Customer Segmentation
5. Product Recommendation
6. Customer Churn Prediction
7. Dashboard Development

## Results

The project successfully identifies sales trends, predicts future demand, segments customers into meaningful groups, recommends products, and identifies customers likely to churn.
